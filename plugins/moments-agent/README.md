# 朋友圈助手（moments-agent）

发一条像样的朋友圈要花很多时间：几百张照片里挑 9 张、调色、排顺序、憋文案。这个插件把**导入 → 挑图 → 调色 → 排版 → 文案 → 导出**串成一条流程，每一步由 AI 给建议、你确认或修改，并且**记住你的习惯**，越用越省事。

## 安装

打开工作台左下角的「工作区文件夹」，复制整个 `moments-agent` 文件夹进去，点「刷新」。打开后界面会自动启动插件引擎。

## 依赖

- 工作台 v0.2+（Windows / macOS / Linux）。脚本用工作台内置的 Node 运行，不需要另装 Node、Python 或 PowerShell 模块，**不带任何第三方库**。
- 扫码传图：手机和电脑连同一个 Wi-Fi。第一次使用时系统防火墙可能询问是否允许，要选「允许」。
- AI（可选）：一个能看图的模型接口。支持 **Claude（Anthropic Messages API，默认 `claude-opus-5-5`）**、**豆包 Seed（火山方舟，预填 `https://ark.cn-beijing.volces.com/api/v3` + `doubao-seed-2-1-lite-260915`）** 和其他 **OpenAI 兼容接口**（例如通义千问 `qwen-vl-max`、智谱 `glm-4v-plus`、Gemini 的 OpenAI 兼容地址）。没配 AI 时，导入、本地预筛、预设滤镜、参考图本地颜色迁移、手动排版、导出都能用。

## 界面（主要入口）

| 步骤 | 做什么 |
|---|---|
| 1 导入 | **扫码从手机相册选图**（手机网页弹出系统相册，可多选，照片陆续出现在电脑上）；或从文件夹导入。原图只复制进草稿，永远不改 |
| 2 挑图 | 本地先筛掉拍糊、曝光有问题、连拍重复的；AI 按构图 / 主体 / 人物 / 色彩 / 审美五项打分（1–10），按权重算总分；组合挑选（同一场景最多 2 张、照顾不同类型）；每张有入选理由，6 张候补，点一下就能换 |
| 3 调色 | 6 个预设滤镜；一句话调色（"日系通透一点，别太黄"，可以连续说"再暖一点"）；复刻同款滤镜（选图或粘贴截图 → 框选照片区域 → 本地颜色迁移 + AI 校正）；左右拖动对比原图；可存为自己的预设 |
| 4 排版 | AI 决定发几张、封面和顺序，规则兜底（4 张 2×2、9 张中心放第二吸引人的、同一场景不相邻）；按朋友圈样式预览，可拖动调整；也支持九宫格切图和拼图 |
| 5 文案 | 按场合和风格生成 3–5 条；内置简短 / 文艺 / 幽默 / 低调 / 日记体；粘贴喜欢的文案可分析出「风格卡」并保存；只模仿风格，和原文有连续 8 个字以上相同的会被丢弃重写 |
| 6 导出 | 照片按顺序命名 `01.jpg`…，默认去掉定位信息；文案复制到剪贴板并存为 `文案.txt`；**扫码存回手机**，或打开文件夹用微信文件传输助手发 |
| 我的偏好 | 冷启动 3 个问题（或上传以前的朋友圈截图让 AI 分析）；AI 记住的全部内容、偏好摘要、预设、风格卡，每条可改可删，可一键清空；草稿管理（保留 30 天，清理前确认并显示释放空间） |
| AI 设置 | 接口地址、API key、模型名；「测试连接」发一张测试图确认模型能看图后才保存；显示调用次数 |

## 动作（清单里的按钮）

界面背后的执行步骤，都会把进度输出到工作台的输出区，可以用「■ 停止」中断。

| 动作 | id | 说明 |
|---|---|---|
| 📱 从手机导入 | `import-phone` | 开启局域网传图，运行到「完成导入」/ 10 分钟无上传 / 停止 |
| 📁 从文件夹导入 | `import-folder` | 弹出文件夹选择框，导入这一层的照片 |
| ✨ 挑照片 | `pick-photos` | 预筛 + AI 打分 + 组合挑选 |
| 🎨 调色 | `color-grade` | 执行界面里输入的一句话调色 / 参考图复刻 |
| 🧩 排版 | `layout` | AI 或规则排版 |
| ✍️ 写文案 | `write-caption` | 生成文案（含风格卡分析） |
| 📦 导出发布包 | `export` | 写文案文件、复制剪贴板、去定位、写入记忆、开启扫码存回 |
| 🧠 我的偏好 | `preferences` | 分析上传的截图，输出记住的偏好 |
| ⚙️ AI 设置 | `ai-settings` | 测试并保存 AI 配置，输出用量 |
| 🔌 启动引擎 | `engine` | `mode: service`。界面打开时自动启动 |
| 🔎 查询引擎地址 | `engine-info` | 界面重新打开时找到正在运行的引擎 |

## 实现说明（宿主能力的补齐方式）

插件通过宿主脚本 SDK 使用文件选择和确认框，传图、图像处理与 AI 流程由插件实现。

- **引擎**：`启动引擎` 动作在本机 `127.0.0.1` 上开一个只给界面用的接口，带随机口令（通过宿主传给当前插件界面）。沙箱界面用 `fetch` 读写草稿、显示缩略图、提交参数——相当于"传参数 + 结构化结果 + 存储接口"。
- **H1 手机传图**：引擎另开一个局域网网页，每次传图生成一次性口令和二维码（插件自带二维码生成），10 分钟没有新上传自动失效；只收图片、单张 ≤30 MB、一次 ≤100 张；HEIF 等无法解码的格式会提示换格式，不影响其他照片。
- **H2 显示本地图片**：界面通过引擎地址加载缩略图。
- **H3 AI 接口**：插件直接调用用户配置的接口。只发长边 1024 的缩略图和文字，不发原图。
- **H4 图片处理**：在界面里用浏览器的 canvas 完成（解码、缩放、清晰度/曝光/感知哈希、调色、切图、拼图、JPEG 编码）。调色先把参数算成 33³ 的颜色查找表，再对整张图插值，9 张 1200 万像素照片可以在几秒内处理完；导出最长边限制为 4096 像素。
- **其余动作**是"瘦客户端"：连到引擎执行对应步骤，所以清单动作和界面看到的是同一份草稿。

## 数据位置

全部在工作台的插件数据目录 `<userData>/plugin-data/moments-agent/` 下，不写包目录：

```
drafts/<yyyyMMdd-HHmmss>/   一次发朋友圈 = 一份草稿（photos/ 原图、thumbs/ 缩略图、发布包/、draft.json 进度）
memory.json                 行为记录、习惯统计、冷启动回答、偏好摘要、挑图权重
presets/  styles/           保存的调色预设、文案风格卡
settings.json               AI 配置（API key 加密）
engine.json                 正在运行的引擎端口和口令
```

**API key 加密**：Windows 用 DPAPI（当前用户，换电脑或换用户无法解密）；macOS / Linux 用 AES-256-GCM，密钥文件只有当前用户可读——能防止配置文件被直接看到或单独拷走，但不等同于系统钥匙串。

## 已知限制

- 手机扫码要求和电脑在同一局域网；公司 / 学校网络如果开启了"客户端隔离"，手机连不上电脑，只能用文件夹导入。
- 部分安卓手机的 HEIF 照片电脑无法解码，会提示在手机相册里换成兼容格式。苹果手机在网页里选图时系统会自动转成 JPG。
- 本版不从小红书、抖音等链接抓取图片或文案，请截图或复制文字。
- 调色只调颜色和明暗，不用生成式模型重绘照片。

## 演示步骤

1. 打开「朋友圈助手」，回答 3 个问题（或跳过）。
2. 「AI 设置」里填 Claude 或兼容接口，点「测试连接并保存」。
3. 「从手机导入」，手机扫码选 30 张照片；电脑上陆续出现。
4. 「挑照片」→ 看入选理由 → 点一张入选的、再点候补换掉。
5. 调色：点「胶片」，再输入"再暖一点"；或粘贴一张喜欢的截图，框选后「复刻同款」。
6. 排版：AI 排版 → 拖动微调。
7. 文案：输入场合，选风格（或粘贴参考文案），生成后选一条、修改、复制。
8. 导出：生成发布包 → 手机扫码按顺序保存。
